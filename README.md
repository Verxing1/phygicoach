# ФиджиКоуч

ИИ-тренер для фиджитал-спортсмена. Прототип для Всероссийского конкурса «Искусственный интеллект: идеи без границ» (2026).

- **Цифровая фаза:** мини-тесты реакции, точности и принятия решений в браузере.
- **Физическая фаза:** нейросеть MediaPipe Pose распознаёт 33 точки тела на видео или с камеры, считает приседания и оценивает технику.
- **Карта спортсмена:** шесть показателей двух фаз на одной диаграмме.
- **План на неделю** по самым слабым показателям и **чат-тренер**.

Всё работает в браузере, видео никуда не отправляется.
